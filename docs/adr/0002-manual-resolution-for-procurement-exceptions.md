# 采购异常交由客服核实处理

采购结果未知或明确失败时，客户均被提示联系客服，由客服核实后补发或退款，首版不自动退款。内部保留“结果未知”与“确定失败”的区别：第三方超时可能已产生扣款，且文档未提供可依赖的按本站请求号恢复订单的接口，因此结果未知时不得自动重新采购。支付成功的事实不因采购异常而改变。

补发和退款通过人工沟通处理，不建设专用的后台补发流程。客户通过网页展示的微信联系方式主动联系，不增加系统主动联系客户或通知客服的流程。

人工处理完成后不要求更新本站订单状态或补录处理结果。因此本站订单可能持续显示原有出卡异常提示，不能据此判断线下补发或退款是否完成；客服需在线下核实历史处理情况，系统不得因该异常状态自动重新采购。
