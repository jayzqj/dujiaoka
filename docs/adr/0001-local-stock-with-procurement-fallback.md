# 本地库存优先，缺货时采购

客户订单优先使用本地库存，仅在本地库存不足时向第三方采购，不将商品整体切换为第三方供货。仅启用第三方补货的商品单次限购一张，前后端同时校验；本地有卡时直接交付，没有时采购一张，不涉及混合交付。

库存数量按本地库存加第三方库存计算。启用第三方补货的商品即使远端库存查询失败，或本地与第三方库存均明确为零，仍允许客户购买一张并付款；库存数量因此不作为此类商品的下单门槛，不虚构库存数量，发货失败后转人工处理。商品上下架、采购暂停等规则仍独立生效。首版仅支持自动发卡商品，每个本地商品绑定一个明确的第三方商品及规格，不支持链接交付、人工交付和额外表单。零元订单只使用本地库存，缺货则转客服，不自动采购。

正常采购由后台执行，客户支付后先看到“支付成功，正在出卡”，成功后页面显示已保存的卡密。接口成功后按固定响应字段 data.secret 提取卡密，不配置按商品区分的卡密格式校验规则；字段缺失、为空或返回明确等待提示时转客服，其余按卡密保存并展示。
